調式練習 · 升四MODES PRACTICE · RAISE FOUR

開口唱練習 · 從大調開始,一次升一個音 · From major, one semitone higher at a time

這是什麼?WHAT IS THIS

從 Ionian(大調)開始,每次把一個音升半音,依序變成 Lydian(利底安)、Locrian(洛克里安)、Phrygian(弗里吉安)、Aeolian(自然小調)、Dorian(多里安)、Mixolydian(米索利底安)。

全曲 13 段、52 小節。每個新調式唱兩段:第一段保留原來的唱名,把升高的音唱 fi(金色);第二段用新調式自己的唱名再唱一次。注意:第 13 小節起,起音升高半音(C 版本由 C 移到 C♯),後面維持這個新起音。

Start from Ionian (the major scale). Raise one note by a semitone at each step: Lydian, Locrian, Phrygian, Aeolian (natural minor), Dorian, then Mixolydian. There are 13 sections and 52 bars. Each new mode is sung twice: first with the old syllables and the raised note sung as fi (in gold), then with the new mode's own syllables. From bar 13, the starting note rises a semitone (C to C♯ in the C version) and stays there.

怎麼練HOW TO PRACTISE

先聽一遍,第二遍開始跟著唱。聽到 fi 就知道調式變了;下一段用新調式自己的唱名再唱一次,對比會很明顯。13 段唱完,換一個起始音再來。

Listen once, then sing along. When you hear fi, the mode has changed; the next section re-sings the same notes in the new mode's own syllables, and the contrast is obvious. After all 13 sections, pick a new starting note and go again.
